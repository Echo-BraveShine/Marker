# Noto Sans SC

Source: https://github.com/google/fonts/tree/main/ofl/notosanssc

`NotoSansSC.ttf` is the regular (weight 400) static instance of the upstream
`NotoSansSC[wght].ttf`, generated with fontTools varLib.instancer. Licensed under
SIL Open Font License 1.1; see OFL-NotoSansSC.txt. Bundled as the Linux UI font and
Chinese fallback on other desktop systems, including editor/preview text.
