# Noto Sans SC

Source: https://github.com/google/fonts/tree/main/ofl/notosanssc

`NotoSansSC.ttf` is the regular (weight 400) static instance of the upstream
`NotoSansSC[wght].ttf`, generated with fontTools varLib.instancer. Licensed under
SIL Open Font License 1.1; see OFL-NotoSansSC.txt. Bundled as the Linux UI font and
Chinese fallback on other desktop systems, including editor/preview text.

# Korean fallback

`NotoSansKR.ttf` is a renamed, subsetted static weight-400 derivative of Google Fonts Noto Sans KR (https://github.com/google/fonts/tree/main/ofl/notosanskr). It includes modern Hangul syllables, Jamo, Latin and punctuation. Its distinct internal family is Marker Noto Sans KR. License: `OFL-NotoSansKR.txt`. The static weight 400/700 derivatives `assets/export/fonts/MarkerKorean-*.woff2` provide offline Korean PDF/HTML/Mermaid rendering.

# Extended Latin fallback

`MarkerSans-Regular.ttf` / `MarkerSans-Bold.ttf` are TTF versions of the existing offline export Latin faces, with distinct Marker Sans family names. They cover extended Latin characters used by Polish and Turkish without requiring system language packs. License and source attribution: `assets/export/marker-fonts-OFL.txt`.
