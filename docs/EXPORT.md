# 导出实现与约束

桌面与移动端共用导出选项。工具栏提供导出入口，桌面快捷键为 ⌘⇧E / Ctrl+Shift+E；手机通过系统文件保存面板保存结果。

## 格式

- PDF：浅色 A4 排版，文字可选择与复制，脚注保留在文末。能容纳一页的段落、代码块、表格与图表尽量保持整体，超长内容按行或表格行拆分。移动端使用原生打印排版，具体分页应在目标系统验收。
- PNG：导出全文长图，可选 960 / 1280 / 1600 px 宽度；支持跟随应用深浅主题，相关偏好持久化。移动端可选分图 ZIP。
- HTML：独立离线文件，内嵌图片、字体、公式和 Mermaid 渲染资源，保留动图。

## 数据与资源

导出捕获入口打开时的文档快照，包含未保存编辑。本地图片以 Markdown 文件目录解析；网络图片先下载内嵌。PDF / PNG 等待图片、字体、公式、Mermaid 渲染完成后输出；缺图、无效语法、网络失败或超时明确报错。

桌面输出通过独立的目标写入逻辑防止覆盖源 Markdown，取消选择不修改已有输出。macOS 可能需要用户授予文档或图片目录访问权限。移动端先生成字节，再调用系统保存面板。文档与资源的 ZIP 打包是另一项功能；移动端开放入口，桌面入口目前隐藏。

## 限制

- PDF / PNG 中的 GIF、WebP、APNG 动图按首帧输出。
- PNG 高度最多 32768 px；移动端单图最多约 1600 万像素，超长内容选择分图 ZIP 或 PDF。分图 PNG 的像素宽度不随设备像素密度变化。
- 移动端分图压缩数据总量最多 64 MB，渲染文档高度最多 200000 px。
- 单张图片最多 25 MB，内嵌资源总量最多 128 MB；每张网络图片下载总超时 30 秒，HTTPS 使用系统证书校验。
- Windows 需要 Edge WebView2 Runtime。构建和自动测试不能替代不同系统、字体、图片及复杂分页的实际输出验收。

## 验证入口

- `flutter test --no-pub`：导出选项、文件保护、图片内嵌、移动端保存流程与分块边界等。
- `bash scripts/ci/test-macos-export.sh`：原生 PDF 脚注、可复制文字、分页和深浅主题 PNG 回归。
- 原生桥接与渲染代码：`lib/src/export/`、`lib/src/widgets/offline_html_renderer.dart`、`lib/src/widgets/mobile_html_renderer.dart` 及各原生工程。
