# Markdown 支持范围

Marker 明确使用 GitHub Flavored Markdown（GFM）解析。Markdown 有多种方言，不存在所有编辑器都通用的“全部标记”。

| 语法 | 当前状态 |
| --- | --- |
| ATX 标题 `# 标题` 到 `###### 标题` | 支持；字号依次 28/22/18/16/15/14 |
| Setext 标题（下一行 `===` / `---`） | 支持 |
| 段落、空行、硬换行、转义 | 解析器支持 |
| 粗体、斜体、删除线、行内代码 | 支持 |
| 引用、有序/无序列表、嵌套列表 | 支持 |
| 分隔线、缩进代码、围栏代码块 | 支持；尚无代码语法着色 |
| GFM 表格 | 支持 |
| GFM 任务列表 | 显示勾选状态；尚不支持点击修改原文 |
| 链接、引用式链接、图片 | 可渲染；支持 http/https/mailto/file 外部打开；图片可用性取决于来源与平台权限 |
| 文字颜色 | 支持 `<span style="color:#RRGGBB">文字</span>`，兼容 #RGB 和常用颜色名；工具栏提供预设色和自定义颜色 |
| 其他原始 HTML | 不作为浏览器 HTML 渲染，不执行任意 CSS 或脚本 |
| LaTeX 数学公式 | 支持 `$...$` 行内和 `$$...$$` 块公式；使用 flutter_math_fork 的 TeX 子集，不执行完整 LaTeX |
| Mermaid 图 | 桌面三端均使用离线打包 Mermaid 10.9.3；macOS/Windows 使用内嵌 WebView，Windows 缓存位于用户数据目录并检查 WebView2 Runtime，页面使用本地文件以避开 NavigateToString 的 2MB 上限；Linux 使用 WebKitGTK 4.1 离线渲染为内嵌图片，并复用随应用打包的中文字体，自动适应高度（最高 8192px）。错误显示具体原因；Web 暂无图形预览 |
| 脚注 | 支持 `[^id]` / `[^id]: 内容`；点击引用滚动到脚注区域，返回链接回到文档顶部，尚非逐条精确定位 |
| 目录指令、自定义容器、高亮 `==文本==` | 未接入对应扩展 |
| 本地相对路径图片 | 相对于当前已保存文档目录解析，支持 `../`、中文及编码空格；macOS 访问受限时可选择授权图片所在目录 |

## 标题看不出区别时

必须使用半角 `#`，其后加空格：`# 一级标题`、`## 二级标题`。`#一级标题`、全角 `＃` 均不属于标准标题写法。围栏代码块内的标记原样展示。可打开同目录的 `markdown-sample.md` 对照。

Linux 编译需 `libwebkit2gtk-4.1-dev`（WebKitGTK >= 2.40），运行需 `libwebkit2gtk-4.1-0`；DEB/RPM 声明相应运行依赖。TAR/AppImage 使用系统 WebKitGTK。Windows 10 如缺少 WebView2 Runtime，需安装 Microsoft Edge WebView2 Runtime。Mermaid 预览不请求在线服务。


### Mermaid 显示一致性与性能

三端预览共用 960 CSS 像素的排版画布、14px 字号和内置 Noto Sans SC 字体，字体就绪后才计算图形布局。相同预览宽度下，图形按相同比例缩放，不再由桌面端固定占用 340px 高度。

预览使用静态快照和最多 24 项 / 24 MB 的渲染缓存；调整分屏宽度、滚动或重新打开相同图形不会再次启动渲染。修改图形后等待 240ms 再渲染，完成前保留旧图。原生渲染串行处理并复用浏览器环境，减少多个图表同时加载造成的卡顿。

## 导出布局与分屏定位

- PNG/HTML 正文最大宽度为 1100 CSS 像素，使用随画布宽度变化的内边距；PDF 为 A4、四边 18 mm。
- 表格占正文可用宽度，单元格长文本换行；代码块、引用、图片与公式均限制在正文范围内。图片和图表保留比例。
- Mermaid 使用内置字体、固定 960 CSS 像素的排版画布，再按正文宽度缩小；不同输出像素宽度和打印尺寸会产生不同缩放，但不随设备重新决定图的布局。
- 分屏按解析后的 Markdown 内容块及源文档行位置双向联动，在块间插值；图片、公式和图表不再通过全文总高度改变后续段落的对应关系。块内部的源码与排版并非逐行等高，长段落与长列表仍按块内进度对应。
