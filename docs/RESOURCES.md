# 文档与图片资源

Marker 保持标准 Markdown 引用。打开已有文档只读取原图片路径，不移动图片、不改写文档，也不创建目录。

## 新建与导入

默认新建一个 MD 文件，首次插入本地图片才创建同名 `.assets` 目录：

```text
项目说明.md
项目说明.assets/
  首页截图.png
  .marker-resources.json
```

资源目录名称冲突时使用不冲突的后缀，不覆盖原有图片或其他文档的管理记录。

- 点击侧栏标题右侧的图片按钮，切换到「资源」。
- 点击「导入图片」，或使用顶部语法栏的图片按钮。
- 可将图片拖到整个文档窗口，包括编辑区、预览区和资源侧栏。编辑区按落点插入，其他区域按当前光标插入；拖入时显示提示。可通过 Cmd/Ctrl+V 粘贴截图或复制的图片文件。
- 原始文件保留。相同内容复用已导入资源，重名但内容不同的文件自动添加序号。
- 没有保存位置的文档会先提示保存；取消不会插入无效引用。
- 「资源」的更多菜单提供「新建文档文件夹」，先创建文件夹和同名 MD，图片目录仍按需创建。

当前可导入 PNG、JPEG、GIF、WebP、BMP。单张图片不超过 50 MB、4000 万像素。原有其他格式的引用不会被静默改写；无法自动处理的语法和图片会显示在结果中。

## 引用原位置与网络图片

默认复制本地图片。「引用原位置」不复制，移动原图可能导致引用失效。

网络图片默认保留 HTTP/HTTPS 网址；在图片菜单中选择「下载到文档资源」可保存为本地图片。普通网址粘贴仍按文本处理，不擅自下载。

## 图片操作与修复

资源列表按本地、网络和异常引用分组。点击一项可以插入到光标位置、打开原图、显示所在目录、复制引用、重新定位、替换或重新加载。同一来源被引用多次时，重新定位和替换会更新全部图片引用，不改普通链接或代码示例。

macOS 通常会为用户拖入的文件授予读取权限；不需要开启全磁盘访问。读取原图失败时，会请求原图所在目录；在 MD 旁边创建资源目录失败时，会请求文档所在目录，这两种授权独立处理。授权会保存为安全书签，重启后尝试恢复。无法读取、缺失或损坏的图片不会阻止文档编辑与保存。

例如文档保存在桌面时，创建 `文档.assets` 可能需要单独授权桌面目录。系统授权面板会说明用途并显示目标路径，点击「允许访问此目录」后继续导入；取消会正常停止，不再重试或显示错误。真正的导入失败会区分「读取原图」和「写入图片资源」，并显示失败位置和系统原因。

## 整理与清理

「整理文档图片」会先展示本地/网络数量、已托管数量和大小。确认后按当前编辑内容整理并保存；原文件保留。网络图片默认不下载，可主动选择一起下载。特殊语法和失败引用保持原样，并列出未处理项。

删除图片引用、撤销图片插入、关闭文档，都不会自动删除图片。

「清理未使用资源」仅处理管理记录中的文件，并核对：

- 当前编辑内容和保存版本；
- 其他打开文档的编辑与保存版本；
- 同目录 Markdown 文档中的图片和普通文件链接；
- 文件是否仍为普通文件、内容是否与导入记录一致。

未知归属、外部修改、符号链接及不能确认引用关系的资源保留。清理前展示图片列表，确认后送入系统废纸篓；废纸篓不可用时保留文件，不退回永久删除。其他工具可能存在尚未登记的引用，清理确认中会提醒检查。

管理记录随资源目录保存；缺失或损坏时仍可阅读图片，原有未知文件不参与自动删除。不要手动将其他文档的管理记录复制到当前目录。

## 另存为与重命名

另存为生成独立副本，复制被引用的本地图片并更新副本中的相对路径，原文件和原标签页保留。未保存修改也会用于副本，原文档不被回写。复制失败时可先修复，或明确选择保留未解决地址；未确认前不发布不完整文档。

重命名会保存当前内容。同时重命名关联的 `.assets` 目录，更新本文图片引用和资源归属记录；目标目录已存在时停止，失败时回滚。其他文档或工具如引用原资源目录，需要同步修改其引用。

文档右键菜单的删除操作改为「移到废纸篓」，默认保留关联图片。

## 打包与恢复

已实现 ZIP 打包：包内包含当前编辑版本及引用的本地图片，可选择下载网络图片，不携带无关图片。存在未解决引用时要求用户确认，并在完成后说明。打包入口继续跟随导出开关保持隐藏。

复制先准备资源，最后发布文档；取消另存为或打包不改动原文档。取消整理会撤销本次新建的资源，不删除复用文件；批量导入停止后保留已经成功插入的图片。废纸篓清理只停止后续项，已移动的文件可从系统废纸篓恢复。

## 验证边界

资源解析、文件操作和编辑流程有自动回归测试；UI 在三端平台配置下验证。macOS 原生插件构建另行检查，Windows/Linux 的原生拖放、剪贴板、目录权限和废纸篓仍需对应系统运行验收。本次不使用本机虚拟机。
