## 设置布局

面板宽 860、高 620，受当前窗口可用空间限制。内容边距为左/右 20、上 12、下 16。左侧分类栏宽 136；后接 12px 间隔、1px 分隔线和 16px 间隔。右侧内容按分类独立保存滚动位置，使用标题和分组卡片。分类包括通用、编辑与预览、快捷键，不使用品牌大图标或宣传文案占据设置空间。设置即时生效，面板仅保留右上角关闭，不设置底部完成按钮。

## 共用表面

语法浮窗、设置、选色、模板、保存/删除确认及文档右键菜单共用 `MarkerFloatingSurface`，统一圆角、背景、边框和阴影。系统文件选择器使用系统界面。工作区正文保留紧凑边距，避免把弹窗的外边距套用到编辑器与预览器。

## 编辑区语法高亮

编辑区文本高亮默认关闭；设置 → 编辑与预览 → 语法高亮中开启“文本高亮”后才显示主题选择。开关与所选风格分别保存，关闭后保留所选风格，编辑内容与选区不变。关闭状态使用纯文本绘制，不执行高亮解析。

主题选择提供经典、GitHub、Solarized、Monokai、Dracula、Nord、One Dark、Tokyo Night、Catppuccin、Rosé Pine、Gruvbox、Ayu 十二种风格，均适配浅色/深色界面。选择即时应用到编辑区与设置预览，并通过 Riverpod + Freezed 设置状态和 SharedPreferences 持久化；不改变 Markdown 原文、字体尺寸、行高及光标选区。

解析采用块级扫描与嵌套行内识别：围栏/缩进代码、标题、引用、列表任务标记、分隔线、表格分隔符、链接/图片、粗斜体、删除线、脚注、引用链接及数学公式。围栏代码按语言使用已有 highlight 库解析；Mermaid 对关键字、连接符和注释分别着色。未知语言和超过 100,000 字符的单个代码块保留统一代码颜色，避免自动语言检测或大代码块解析影响输入。缓存当前文档结果及最近 16 个语言代码块的解析结果。输入法组合区增加下划线，保留语法颜色。

## 文档侧栏

默认展开宽 220、折叠宽 56。展开后可拖动右侧 5px 命中区域，在 180–320 之间调整；拖动结束保存宽度，重启恢复。切换展开状态即时调整，避免动画中间宽度挤压内容。右键菜单共用浮窗表面和 13px 正文，操作图标 16px，删除项使用红色并以细线分隔。高亮主题选择使用自适应二/三列卡片，每张显示名称、色样与选中标记。

快捷键分类的标题、外层圆角边框和说明固定，仅内部快捷键列表滚动。Linux 使用随包的 Noto Sans SC Regular，编辑与预览的等宽样式追加该中文回退字体。


### Linux 中文字体约束

参考 EJson 的 WorkbenchTypography，内置中文字体使用项目独立别名 `Marker Noto Sans SC`，统一由 `MarkerFonts` 提供 UI、等宽与衬线回退链。Linux 控件、弹窗正文和按钮直接使用内置字体；模板、代码、高亮示例、快捷键与编辑器使用平台等宽字体，并保留中文回退，禁止各自硬编码 Apple 字体。

Mermaid 在排版前加载内置字体。公式组件内部不继承界面字体，因此中文字符使用单独的字体适配，保留原有数学符号字体与分式/矩阵布局。GTK 应用与图形安装器都在初始化界面前通过 Fontconfig 注册随包字体，不改动系统字体目录。Linux 打包检查同时确认字体和许可证存在。
