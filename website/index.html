开始前，你可能想知道。
我的文档保存在哪里？
电脑上由你选择保存位置，手机上保存在 Marker 的应用文档中。文档留在本机，目前不提供跨设备云同步。
手机打开文档后，怎样一起带上图片？
如果文档引用了本地图片，先把 Markdown 和图片按原目录打成 ZIP，再导入 Marker。只选择 Markdown 文件，手机可能无法读取旁边的图片。需要转移时，也可将文档和图片打包导出。
手机端怎样使用？
手机端仅支持横屏，编辑、分屏和预览与电脑保持一致。Android 默认隐藏系统栏，可从屏幕边缘滑动唤出；文档操作可长按或点击更多按钮。
没有网络也可以写作吗？
可以。本地文档、图片、公式和图表可离线编辑与预览。网络图片、检查更新和下载新版本需要联网；导出包含网络图片的文档时，也需要先下载图片。


AT HOME ON YOUR DEVICES
给想法，一个落脚的地方。

macOS
Apple Silicon / Intel
M 系列选择 ARM64，Intel 选择 x86_64。打开 DMG，拖入 Applications 即可；通用 ZIP 同时包含两种架构。
Windows
x64
通常选择 EXE 安装包，可切换中英文；也提供 MSI。不想安装时，可选择便携 ZIP。
Linux
x64 / ARM64
按系统选择 DEB 或 RPM；也可使用 AppImage 或解压 TAR。TAR 内附中英文安装引导。
Android
ARMv7 / ARM64 / x86_64
下载 APK 并安装，转动手机即可横屏写作。可以拍照、从相册添加图片，并导出写好的文档。
iPhone 与 iPad 版本暂未开放下载。
全部版本与更新说明这里只展示已发布的安装包。若暂无适合你的版本，可查看全部发布记录。
